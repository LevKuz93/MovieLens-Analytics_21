# MovieLens-Analytics_21
Анализ MovieLens_подготовить собственный аналитический отчёт по данным MovieLens

> Модульный аналитический инструмент и Jupyter-отчет по исследованию структуры данных MovieLens на базе кастомных классов и PyTest.

---

##  Ограничения и Стек

* **Окружение:** Python 3, Jupyter Notebook
* **Разрешенные библиотеки:** `os`, `sys`, `urllib`, `requests`, `beautifulsoup`, `json`, `pytest`, `collections`, `functools`, `datetime`, `re`
* **Ограничение выборки:** Первые 1000 записей датасета MovieLens.
* **Правило ячеек отчета:** Каждая аналитическая ячейка обязана использовать магическую команду `%timeit`.

---

##  Архитектура проекта

Проект разделен на две логические части: кастомный модуль и интерактивный отчет.

* `movielens_analysis.py` — модуль, содержащий бизнес-логику и парсинг данных.
* `movielens_report.ipynb` — аналитический отчет

### Основные классы модуля:
* **`Movies`** — парсинг, категоризация и фильтрация каталога фильмов.
* **`Ratings`** — расчет распределения оценок, средних баллов и активности пользователей.
* **`Tags`** — анализ пользовательских тегов и ключевых слов.
* **`Links`** — связь ID датасета с внешними идентификаторами (IMDb/TMDb).
* **`Tests`** — класс сквозного тестирования функционала.

---

##  Полученные навыки 

* **Парсинг и ETL (Extract, Transform, Load):** Опыт автоматического сбора данных, извлечения метаданных и работы со структурами веб-ресурсов о кино.
* **Кастомная разработка на Python:** Навыки создания чистого, тестируемого объектно-ориентированного кода (ООП) с жесткими ограничениями на внешние библиотеки.
* **Продуктовая аналитика:** Умение находить скрытые паттерны в данных, проводить бенчмаркинг скорости кода (`%timeit`) и покрывать логику тестами (`PyTest`).
* **Storytelling & Data Journalism:** Опыт создания понятных, логичных и увлекательных аналитических отчетов в Jupyter Notebook, которые переводят сухие цифры в интересные инсайты.
